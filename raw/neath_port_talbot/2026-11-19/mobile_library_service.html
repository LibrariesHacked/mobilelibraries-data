Overview

Our mobile library visits Neath Port Talbot communities that do not have a local library.

If you're a library member you can:

  • browse the mobile library shelves and borrow up to 20 items
  • return items from Neath Port Talbot libraries to the mobile library
  • return items from the mobile library to any library in Neath Port Talbot

You can join at the mobile library, or you can become a library member online.

Mobile library timetable

Mobile libraries in Neath Port Talbot operate on a 3 week cycle. There are no stops at weekends and no service on Bank Holidays.
